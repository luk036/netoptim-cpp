Detailed Description

template<typename Graph, typename Fn>
class netoptim_detail::Ratio< Graph, Fn >

Adapter: evaluates the scaling-ratio constraint for one edge.

Provides the eval / grad interface expected by NetworkOracle, adapting a cost function (edge -> (a_ij, a_ji)) to the constraint h_ij(x) = min(pi - a_ji, a_ij - psi) with x = (pi, psi) in log scale.

Template Parameters
GraphType of the directed graph representing matrix sparsity
FnType of the cost function (edge -> matrix entry pair)

Evaluate the constraint function for an edge.

Computes min(pi - a_ji, a_ij - psi) where x = (pi, psi) in log scale. A positive result indicates the constraint is satisfied. The edge parameter is the graph's native edge data (e.g., the (a_ij, a_ji) cost pair from the adjacency structure).

[in]xvector containing (pi, psi) in log scale

Compute the gradient of the constraint function.

Returns a subgradient vector indicating which bound is active: [1.0, 0.0] if the upper bound (pi) is active, or [0.0, -1.0] if the lower bound (psi) is active.
