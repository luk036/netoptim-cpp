Detailed Description

Convenience facades for driving netoptim oracles with the ellipsoid cutting-plane method.

Mirrors the Python sibling's solve_network_feas / solve_opt_scaling facades: both forward an Options object (defaulting to a sensible tolerance) to the ellalgo drivers, and the feasibility facade uses the feasibility driver (cutting_plane_feas).

◆ kDefaultTolerance

constexpr double kDefaultTolerance = 1e-10
inlineconstexpr

Default convergence tolerance used by the solver facades.

Benchmarked with bench_optscaling on the project's fixed graph: the objective error scales as sqrt(tolerance), so 1e-10 yields ~1e-5 error at ~28% more runtime than 1e-8 (~1e-4 error). ellalgo's built-in 1e-20 is unreachable at double precision for most scales and only inflates the iteration count. Pass an explicit Options to override.
